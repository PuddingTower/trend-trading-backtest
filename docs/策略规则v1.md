# 策略规则 v1 规范

策略规则是纯 JSON 文档，可导入、导出、校验和交给寻优 Worker。它不执行 JavaScript，也不接受任意表达式字符串。

## 两种文档

### builtin：引用内置策略

```json
{
  "schemaVersion": 1,
  "kind": "builtin",
  "id": "maCross",
  "revision": 1,
  "params": { "fast": 8, "slow": 26 }
}
```

### rules：自定义 JSON 规则

```json
{
  "schemaVersion": 1,
  "kind": "rules",
  "id": "ma_above",
  "name": "收盘站上均线",
  "revision": 1,
  "parameters": {
    "fast": { "type": "integer", "default": 20, "min": 1, "max": 500, "label": "均线周期" }
  },
  "requires": { "fields": ["open", "high", "low", "close", "volume"] },
  "series": {
    "ma": { "op": "sma", "source": { "field": "close" }, "period": { "param": "fast" } }
  },
  "rules": [
    {
      "when": {
        "op": "greaterThan",
        "left": { "field": "close" },
        "right": { "series": "ma" }
      },
      "do": { "action": "long", "reason": "收盘站上均线" }
    }
  ]
}
```

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---:|---|
| `schemaVersion` | 是 | 固定为 `1` |
| `kind` | 是 | `builtin` 或 `rules` |
| `id` | 是 | 稳定的英文标识；同一浏览器会话内按 `revision` 升版 |
| `name` | `rules` 必填 | 显示名称 |
| `description` | 否 | 说明，不参与执行 |
| `revision` | 是 | 大于 0 的整数 |
| `parameters` | 否 | 自定义规则参数定义 |
| `requires` | 否 | 所需行情字段 |
| `series` | 否 | 命名指标序列 |
| `rules` | `rules` 必填 | 有序条件规则，首条命中生效 |
| `metadata` | 否 | 预留作者、标签等非执行信息 |

未知字段会被拒绝，避免 AI 写错键名后静默失效。

## 参数

支持的类型：

- `integer`
- `number`
- `boolean`
- `string`

定义属性：

- `default`：必填。
- `min` / `max`：数值范围。
- `step`：控件步长。
- `enum`：`[[value, label], ...]`。
- `label`：中文标签。
- `description`：提示。

参数引用使用：

```json
{ "param": "fast" }
```

## 行情依赖

`requires.fields` 只允许：

- `date`
- `open`
- `high`
- `low`
- `close`
- `volume`

计算开始前会逐根检查所需字段。缺失时明确报 `REQUIRED_FIELD_MISSING`，不会把缺数据当成条件不成立。

## 指标序列

```json
"series": {
  "ma": {
    "op": "sma",
    "source": { "field": "close" },
    "period": { "param": "fast" }
  }
}
```

| `op` | 用途 | 是否需 `source` |
|---|---|---|
| `sma` | 简单移动平均 | 是 |
| `ema` | 指数移动平均 | 是 |
| `rsi` | RSI | 是 |
| `atr` | ATR | 否，使用 bars 的高低收 |
| `priorHigh` | 上一根为止 N 根最高价 | 是 |
| `priorLow` | 上一根为止 N 根最低价 | 是 |

所有序列与 K 线等长，暖机期为 `null`。暖机期不会参加数值比较。

## 数值引用

- 行情字段：`{"field":"close"}`
- 指标序列：`{"series":"ma"}`
- 常量：`{"const":20}`
- 参数：`{"param":"fast"}`
- 算术表达式：

```json
{
  "op": "subtract",
  "left": { "field": "close" },
  "right": { "const": 5 }
}
```

支持：`add`、`subtract`、`multiply`、`divide`。除数为 0 时返回 `null`，结果视为未命中。

## 条件操作符

组合条件：

- `and`：`conditions` 数组。
- `or`：`conditions` 数组。
- `not`：单个 `condition`。

数值比较：

- `greaterThan`
- `lessThan`
- `greaterThanOrEqual`
- `lessThanOrEqual`
- `equal`
- `notEqual`

交叉条件：

- `crossUp`
- `crossDown`

交叉必须同时具备当前根和上一根的有效数值，只发生在穿越确认的当前根。

## 动作

| 动作 | 信号含义 |
|---|---|
| `noop` | 无操作，输出 `null` |
| `long` | 目标多头，输出 `dir: 1` |
| `short` | 目标空头，输出 `dir: -1` |
| `close` | 显式平仓，输出 `dir: 0` |

未命中任何规则时默认无操作。`noop` 和 `close` 是不同语义。

动作支持：

```json
"do": {
  "action": "long",
  "reason": "突破",
  "risk": {
    "stop": { "field": "close" },
    "target": { "const": 5000 },
    "trail": { "op": "subtract", "left": { "field": "high" }, "right": { "const": 20 } }
  }
}
```

`stop`、`target`、`trail` 必须求值成绝对价格。参考时点是产生信号的当前 bar；撮合仍在下一根开盘执行。

## 执行边界

v1 支持：

- 单品种 OHLCV 规则。
- 多空目标、显式平仓和反手。
- 初始止损、止盈和移动止损候选价。
- 自动回测、网格寻优、TPE、Walk-Forward、策略对比。
- JSON 导入导出、内容哈希和版本拒绝。

v1 不支持：

- JavaScript 或任意表达式字符串。
- 跨品种与横截面排名。
- 外部 RS 基准。
- 组合回测中的自定义规则。
- 限价、止损市价、分批加仓等任意订单结构。

## 资源限制

- 规则文本：最多 256,000 字符。
- JSON 节点：最多 2,048 个。
- 嵌套深度：最多 64 层。
- 非法规则不会进入回测或 Worker。

## 导入与导出

回测面板：

1. 点“导入规则”选择 `.json`。
2. 校验失败显示错误码和 JSON 路径。
3. 校验成功后策略出现在下拉列表。
4. “导出规则”导出当前内置策略参数或当前自定义规则文档。

导出内容会先规范化。重新导入同一份文档得到相同内容哈希。

## 结果身份

每次自定义规则回测都记录：

```text
策略内容哈希 #16 位十六进制
```

规则逻辑、参数定义或风控表达式一变，内容哈希必变。仅凭 `id` 不再足以复现历史结果。

## 默认规则

应用启动时自动加载两条 1 小时趋势规则，回测面板与研究面板直接可选，显示为「默认规则 r1」：

| id | 名称 | 用途 |
|---|---|---|
| `intraday_ema_band_both` | 1H EMA趋势带(期货多空) | 期货等可做空品种 |
| `intraday_ema_band_long` | 1H EMA趋势带(只做多) | A股/ETF 等不能做空品种 |

它们来自 1 小时多品类研究，参数不是实盘建议；样本只有约 5–12 个月（各品种覆盖不同），且多空版单品种尾部风险仍大。
研究口径、样本外结果与使用边界见 [`docs/1h趋势策略研究.md`](1h趋势策略研究.md)。
默认规则同样走 `rules` 校验与内容哈希，不允许用同 revision 的导入文档静默覆盖。

## AI 生成提示

把下面要求连同本规范一起交给 AI：

```text
只输出一个策略规则 v1 JSON 文档，不输出 Markdown、解释或 JavaScript。
必须使用本规范中的操作符白名单和字段结构。
未知字段必须省略；参数必须提供 type/default。
必须显式区分 noop 与 close。
止损、止盈、移动止损必须是信号当前 bar 可求值的绝对价格表达式。
输出前检查 schemaVersion=1、id、name、revision、requires、series、rules。
```
